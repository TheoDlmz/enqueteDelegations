# Enquête sur les délégations de vote à l'Assemblée nationale

Ce repository contient le code permettant de récuperer les données de l'article de blog sur les délégations de vote à l'Assemblée nationale : [https://theo.delemazure.fr/blog/assemblee/delegations.html](https://theo.delemazure.fr/blog/assemblee/delegations.html)

Pour executer le code, il faut unzip les données qui se trouvent dans le dossier data/ et data/scrutins/.
